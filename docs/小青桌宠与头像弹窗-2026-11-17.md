# 小青桌宠与头像弹窗

## 本次交付

20个页面共用绿色小青桌宠。拖动后贴靠左右边缘，跨页保留相对位置，调整窗口大小时限制在可见区域内。点击展开聊天，支持方向键移动、Escape收起，以及系统减少动态效果设置。桌面聊天窗在桌宠旁展开，小屏使用适应视口的浮窗；头像编辑弹窗位于桌宠之上。

桌宠启动脚本不加载React或请求对话；首次展开才加载独立聊天包。聊天复用原有小青的流式显示、停止、重试、来源卡片与账户鉴权。新对话可根据当前页面的公开岗位参数选择方向；页面提示仅使用固定文案，不自动读取正在作答内容。结合最近练习摘要仍需用户勾选。

当前标签页按账户保存最后打开的会话ID，正文仍从服务端验证归属后读取。收起浮窗保留本页状态，跨页可恢复已保存会话；离开页面时正在生成的临时内容不承诺连续传输。账户资料更新不再清空同一登录会话中的聊天，切换身份仍清理旧账户内容。

账户概览头像与资料编辑卡片均可打开居中白色头像弹窗。支持选择图片或拖放一张图片、裁剪拖动、缩放、水平/垂直调整、圆形预览及128/256/512像素输出。客户端校验JPG/PNG/WebP、非空且不超过2MB，图片尺寸沿用32至4096像素校验，服务端继续独立验证。取消不上传，确认后仅上传裁剪后的PNG，保存成功刷新资料与顶部头像。手机端标题、关闭及保存操作保持可见。

## 维护入口

- `ui/shared/qing-pet.js`、`petposition.js`：桌宠、拖动、吸边及延迟加载。
- `frontend/widget/`：悬浮聊天；`frontend/assistant/memory.ts`：按账户记录会话ID。
- `ui/modules/account/avatar.js`：头像弹窗状态与上传。
- `ui/styles/91-avatar-dialog.css`、`99-qing-pet.css`：响应式布局和动效。
- `tools/build_frontend.mjs`、`build_ui.py`、`project.py`：三个React入口、哈希校验及打包资源。

开发后执行frontend目录的`npm run build`，再在根目录执行`python tools/project.py build`。源码打包包含widget目录，首页静态包包含桌宠和延迟聊天资源。
