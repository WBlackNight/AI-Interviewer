# 青栈 QINGZHAN · API 清单（2026-11-17 核查）

> 核查方式：从 `app.openapi()` 导出接口描述（74 条路径 / 86 个 HTTP 操作），再对每个操作做一次无凭据探测，确认没有 5xx；WebSocket 与页面路由不在 OpenAPI 内，按源码单独核对。
> 在线文档：<http://localhost:3000/docs>　规范文件：<http://localhost:3000/openapi.json>
> 本文档对应代码：`backend/app/api/*`、`backend/app/schemas.py`。

## 一、核查结论

| 项目 | 数量 | 说明 |
| --- | --- | --- |
| HTTP 操作 | 86 | 分布在 74 条路径上，含 GET/POST/PATCH/PUT/DELETE |
| WebSocket | 2 | 文字/语音练习室、实时语音陪练 |
| 页面路由 | 15 + 2 动态 | 非 API，由后端同源 `attach_frontend` 提供 |
| 探测结果 | 0 个 5xx | 公共接口 200；需登录 401/403；参数不符 422；PDF 非 multipart 415 |

探测中观察到的正常行为：`/api/health`、`/api/catalog`、`/api/positions`、`/api/practice/config`、`/api/diagnostics/*` 等公开接口返回 200；`/api/account/*`、`/api/assistant/*` 无凭据返回 401；`/api/interview/{id}/*` 无凭据返回 403；`/api/admin/*` 无管理员身份返回 401/403。

## 二、鉴权模型（4 种凭据）

| 凭据 | 传递方式 | 获取 | 适用 |
| --- | --- | --- | --- |
| 账户会话 | `Authorization: Bearer <64 位 hex>` | `POST /api/auth/login` 返回 `access_token`（含 `expires_at`） | 所有 `/api/account/*`、`/api/assistant/*`、`/api/admin/*`，以及账户拥有的面试/简历 |
| 匿名面试凭据 | `X-Interview-Token: <64 位 hex>`；WebSocket 用子协议 `['interview', token]` | `POST /api/interview` 匿名创建时返回 | 单个面试的查询、取消、报告、导出、再练 |
| 简历凭据 | `X-Resume-Token: <64 位 hex>` | `POST /api/resume`（或 `/api/resume/pdf`）返回 | 创建面试时绑定简历 |
| 报告分享令牌 | `X-Report-Share: <64 位 hex>` | `POST /api/account/interviews/{id}/shares` 返回 | 公开读取脱敏报告 `/api/shared-report` |

补充规则：

- **账户拥有的资源**（登录后创建）不再签发匿名令牌，直接用账户会话令牌作为资源凭据；资源归属由 `ResourceOwner` 校验。
- **管理端**要求账户 ID 出现在 `ADMIN_ACCOUNT_IDS`（只读查看者用 `ADMIN_VIEWER_ACCOUNT_IDS`）；`review`、`audit`、`export` 三个权限仅管理员具备。
- **WebSocket 额外校验** `Origin` 必须在 `CORS_ORIGINS`（默认 `http://localhost:3000`）。
- 登录/注册类接口按来源地址限流，超限返回 429。

## 三、通用约定

- 错误体统一为 `{"detail": "中文说明"}`；401 未登录/凭据失效，403 无权限或资源不属于当前账户，404 不存在，409 版本冲突，422 参数校验失败，429 限流。
- 分页参数 `offset`（≥0）与 `limit`（≤50；管理端默认 10）；时间范围用 `start`/`end`（日期）。
- 并发控制：修改/删除复习任务、计划、题单、助手会话时携带 `expected_version`；题单批量与题目审校还需 `content_hash`。
- 响应头：页面与敏感数据 `Cache-Control: no-store`；CSV 导出带 `Content-Disposition: attachment`。
- WebSocket 限流：文字消息 60 条/分钟；音频帧 900 帧/分钟；实时陪练单连接默认 120 秒、不自动重连。

## 五、WebSocket（2）

| 路径 | 协议要点 |
| --- | --- |
| `ws://localhost:3000/ws/interview/{interview_id}` | 练习室（文字/正式语音）。握手：子协议 `interview` + 资源令牌第 2 段；`Origin` 必须受信。客户端发送 `{"type":"start"}` 拿快照；每轮 `{"type":"answer","message_id","turn_id","version","text","code?"}`；还支持 `interrupt`、`read_question`、`audio`（PCM 分片）、`audio_end`。服务端事件：`snapshot`、`question`、`answer_ack`、`score`、`agent_message`、`closing`、`report_ready`、`state`、`greeting`、`error`，语音另有 `asr_partial`、`asr_final`、`tts_chunk`、`tts_end`、`barge_in_ack`、`voice_*` |
| `ws://localhost:3000/ws/realtime/{interview_id}` | 实时语音陪练。需 `VOICE_ENABLED` 且 ASR/TTS 均为 `doubao`，场次未结束。服务端先发 `{"type":"ready","max_seconds","question"}`；之后下发 `listening`、`caption{role,text,final}`、`speaking`、`audio{data}`、`audio_end`、`interrupted`、`ended`、`error{code}`。客户端上行 `{"type":"audio","seq","data"}`（16kHz PCM16 单声道）与 `{"type":"interrupt"}`。单连接默认 120 秒，不自动重连 |

## 七、关键请求/响应示例

### 7.1 创建面试

```http
POST /api/interview
Authorization: Bearer <账户令牌>        ← 匿名时省略，改用 X-Resume-Token
Content-Type: application/json

{"position": "java_backend", "difficulty": "mid", "themes": ["JVM", "Redis"], "duration_minutes": 10}
```

```json
{
  "access_token": "64位hex，匿名时返回；账户创建时为 null",
  "account_owned": true,
  "interview_id": "32位hex",
  "position": "java_backend",
  "plan": [{"theme": "JVM", "weight": 0.5, "difficulty": "mid", "question_count": 2, "include_coding": false}],
  "ws_url": "/ws/interview/32位hex"

```

`overall`、`dimensions`（技术深度/表达逻辑/岗位匹配）、`weak_points`、`recommendations`、`per_question[]`（题干、回答、得分、命中/遗漏关键点、`evidence` 原文引用、`scoring_origin` 分数来源与版本）、`scoring_sources`、`answer_count`、`is_complete`。
