# 账户与数据生命周期（2026-10-23）

本批实现范围：本地用户名/密码账户、可撤销会话、匿名面试认领、账户分页历史及删除。无邮件/短信供应商，无密码找回；账户不等同于既有上传简历创建的User行。跨场能力画像后置。

1. 用户名为3–32位ASCII字母/数字/下划线，大小写归一；密码12–128字符，使用随机盐的PBKDF2-HMAC-SHA256（600000次）保存，明文不入库/日志。选择标准库实现以复用现有运行环境，参数参考[OWASP密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。生产仍需独立安全审核与分布式限流。
2. 登录签发256位随机会话，数据库只存SHA256散列；7天到期，退出仅撤销当前会话。浏览器凭据仍只存sessionStorage；关闭标签页后重新登录，从数据库找回历史。HTTP账户接口用Authorization: Bearer；资源接口的原X-Interview-Token/X-Resume-Token及WS子协议也接受所属账户的有效会话，不把凭据放URL。
3. 新建时提供有效账户Authorization，资源归该账户，返回account_owned=true、access_token=null；资源访问使用账户会话。未登录仍返回原匿名资源凭据，原流程不变。无效账户凭据明确拒绝，不静默落为匿名创建。
4. 认领仅支持逐场面试，要求账户会话及该面试的匿名凭据。所有权以独立表的资源复合主键唯一约束，不能抢占他人资源；同一账户重复认领幂等。认领删除匿名授权，老凭据失效；已有连接在下一消息和轮次提交前重新校验。只认领所选面试，不顺带认领原简历或其他面试。
5. 账户历史只列所属面试，每页20条、最多50条，按归属时间及ID稳定排序。其他账户不能读取摘要、报告、导出、用量、复练或WS。专项/复练沿用来源归属。跨设备需连接同一后端并重新登录，不承诺数据库之外的同步服务。
6. 记录保留至用户主动删除。可删除已完成、已取消或尚未开始的所属面试；进行中返回409，先完成或取消再删除。取消需要资源凭据及二次确认，保留已提交回答/来源/部分报告，不能恢复本场，不计入已完成跨场对照；未提交草稿不上传。取消提升版本并阻止迟到评分提交，已提交评分保留；题库版本变化或损坏旧快照不阻碍取消。删除清理回答/评分、事件、运行快照、幂等提交、轮次关联、匿名授权及归属记录。账户删除要求再次输入密码，全部所属面试均非进行中才执行；同时清理所属简历、无其他引用的匿名User行、会话和账户。操作单事务；共享题库/技能树不删除。账本只保留资源ID和计费计数供对账，不含回答/简历/账户凭据，自动过期清理后续实现。取消不会撤销已经发出的供应商请求或退还其用量。
7. 本地开发不建立自动备份；已有数据库备份、平台日志、外部供应商副本不由数据库删除接口清理。正式发布前必须补备份保留/恢复后重放删除、供应商数据保留、自动清理、账号找回和多worker配额。此批不是生产身份平台或完整数据合规验收。

本次来源归档补充：score_origin保存评分来源、错误类别、模型/配置/提示词版本摘要、题目摘要及实际难度，不存异常正文、提示词或额外回答副本。它与评分同事务保存，删除评分/账户时同步清理。跨场接口仅读取所属已完成记录的汇总，不返回回答或题干；删除旧记录后重复题统计随之重算。旧评分没有来源和版本时保持未知，不通过当前供应商配置回填。

复习任务补充：用户点击加入时，revision_task保存账户/来源面试ID、岗位/主题、加入时主题分数/阈值、最多8个去重未覆盖要点（每项最多300字符）及手动状态/时间，不额外复制回答、题干或简历。仅账户所属已完成面试可加入，匿名须先认领；同账户/来源/主题唯一，重复加入保留已有进度。任务保留至来源面试或账户删除，同事务按外键顺序先清理任务；他人不能列表或更新。手动标记不更新评分和能力画像，无自动提醒或外部发送。下载附件由浏览器保存在用户本机，不会随服务端删除而自动清理。

任务专项补充：revision_practice只保存递增关联ID、任务ID和新面试ID，不额外保存用户内容。新专项拥有独立账户归属；创建/继续/完成都不改变任务手动状态。删除原报告导致任务清理时，先删除关联，已创建的专项内容独立保留，报告不再显示已删除来源；用户可按普通面试规则完成/取消后删除专项。删除专项仅删除该场及对应关联，任务保留，最新练习摘要随之重算。账户删除按原进行中保护规则处理，允许时清理所有关联、任务及所属面试。原始来源不会被复制到新专项的简历、回答或评分中。

复习日期补充（2026-10-24）：revision_schedule仅保存任务ID及用户指定日历日期，不含回答/简历或外部凭据。日期统一按北京时间判断，可改期或清空；完成/恢复/专项练习保留日期。删除来源/账户时同事务先删除对应日期行，再清理任务；删除独立专项不影响原任务安排。没有自动通知或向外部供应商发送复习日程。

个人笔记补充（2026-10-24）：revision_note保存任务ID、用户显式提交的最多2,000字纯文本、并发版本与UTC更新时间，仅账户所属任务可读取/修改，响应no-store。未保存草稿只存在页面内存。笔记不发送给模型、不进入评分/规划/追问/运行快照或报告导出；任务状态、日期和分数不因保存改变。清空保留空文本与递增版本用于拒绝旧请求，不保留历史文本；删除来源面试/账户时在同一事务删除笔记行，删除独立专项不影响源笔记。已有备份副本仍按原备份边界管理。

复习搜索补充（2026-10-24）：搜索仅在当前账户任务及已保存笔记内按字面子串匹配，不包含未保存草稿、其他账户或外部模型。主题与笔记不另建搜索副本，保存/清空后下一次查询使用当前数据库内容；删除源记录后不留下独立搜索档案。关键词通过带授权的GET参数提交，页面地址及浏览器持久存储不保存；生产访问日志、备份副本仍需按既有账户内容策略管理。

原生账户与记录补充（2026-10-24）：原生页复用相同会话与资源键，不建立额外身份库。登录/注册后只持久化会话，密码在提交后清空，删除确认撤回也清空密码。记录的岗位/强度/状态过滤只在归属查询内部生效，状态计数不跨账户；默认API每页20保持，原生每页8。匿名只从当前标签页发现最多50条合法资源凭据，不枚举服务器ID；认领成功清该匿名键，退出仅清当前账户会话。取消与永久删除在独立对话框确认，撤回不发送写请求。布局改造没有更改保留期限、删除保护、外部处理或报告导出范围。

准备计划补充（2026-10-27）：preparation_plan保存账户、名称、岗位、固定主题与强度、可空目标日、手动active/archived状态、版本和UTC创建/更新时间；preparation_practice只保存计划/独立面试关联。名称和日期不进入模型、评分、报告数据/导出或面试快照。范围只能新建，改名/改期不修改已有面试；日期按北京时间日历处理，不自动通知。归档可恢复，不取消已有练习；移除需先归档及版本确认，只清计划和关联，所属练习/报告保留。删除练习在原事务清对应关联，完成计数按仍存关联重算；删除账户按原进行中保护规则清理全部计划与关联。新建/编辑草稿仅页面内存，身份失效清旧页面内容；密码、个人计划名称不进入URL或日志。备份和已下载内容沿用原有边界。

计划衔接补充（2026-10-27续）：报告来源由独立账户接口实时读取计划名称/状态/日期，不进入原报告、JSON/Markdown导出或评分。读取须面试与计划同属本账户；来源计划移除后返回null，练习删除后404。概览只返回所属计划计数及最多3份活动计划的id/name/position/target_date，不建立副本。来源定位URL仅含计划ID，不含名称、日期或会话；他人/已移除计划均为空列表。归档、移除、备份和下载内容沿原边界管理，无新保留期限或供应商处理。

计划练习记录补充（2026-10-27续）：新列表按计划及面试共同归属授权，只返回本页摘要和过滤前四状态计数，不新增内容副本、表或列。状态/页码与计划ID可在地址恢复，不含名称、日期、凭据或答案。列表不改计划、评分或练习状态；用户主动进入原练习室才沿原规则开始/继续。归档可读，删除练习清关联并重算，移除计划后404而原报告仍可访问。API沿用no-store；页面检验同一会话令牌、异步版本和失效隐藏，离页中断读取，不产生新保留期限。

主流程主题复盘补充（2026-10-27续）：新增计划范围只读复盘接口，计划、面试及岗位范围先于评分摘要读取，不新增评分或个人内容副本。默认只读单主题四场，未完成/取消不展示；重复题仍沿用本账户完成记录口径。加入任务仍为用户显式POST，按原报告弱项规则幂等，状态/日期/笔记保持；复练产生独立场次，手动已复习状态不变。共享前端请求校验读取版本与同一会话，保存无自动重试，离页中断并拒绝旧结果回写。无新保留期限、供应商发送或表列。
