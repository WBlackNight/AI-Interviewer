# 开发日志：P2.4离线混合检索

日期：2026-10-21（Asia/Shanghai）。接续[PDF开发日志](开发日志-2026-10-21.md)，依据[技术实现步骤](技术实现步骤.md)步骤2.4。

## 范围与交付

按用户“暂无，先完成离线链路”的选择，实现可运行的BM25/离线哈希向量/RRF三种检索、统一候选过滤、独立索引构建、版本校验、故障回退、快照兼容和固定查询评测。**默认保持BM25**，没有连接外部embedding服务或下载模型。

离线向量使用`hash / char-ngram-hash-v1 / revision=1 / dimensions=256 / L2 / cosine`。字符1–3 gram经SHA256映射到固定维度，是词法基线，不是训练出的语义表示。`Embedder`协议为后续真实模型保留接线位置，本轮不声称完成语义模型接入或检索质量提升。

## 候选、索引与恢复规则

岗位、主题（若指定）、题型和已问排除始终是硬约束。指定难度没有未问候选时，可显式允许放宽难度；其他约束不放宽。BM25和向量在同一候选池内排名，防止其他岗位/已问题占满top-k。空候选不计算向量，候选耗尽返回None。两个支路输入都为主题+题干，不给某一支路额外参考答案。

RRF默认`k=60`，每支路每题最多贡献一次`1/(k+rank)`，不混加BM25与余弦原始分数。默认每支路候选上限20（若请求top-k更大则相应扩大）；当前11题不需向量数据库。

索引payload包含题目ID、来源、岗位、主题、难度、题型、题目摘要；manifest包含完整题库摘要、模型ID/修订/维度/归一化/度量、文档表示版本与索引摘要。同维度但模型/修订不同仍拒绝旧索引。题目锚点/测试用例变化也进入题目摘要。

相同索引重复构建不计算向量、不改写文件。构建在同目录临时文件写完并fsync后原子替换；提取/写入/替换失败保留原索引。加载检查32MiB文件上限、题目集合/载荷/向量维度/有限值/规范化/摘要。摘要用于一致性检查，不是来源认证或安全签名。

缺失/失效索引、embedding或向量查询异常会记录固定原因并回退BM25，原始异常正文和查询不写日志。在线会话允许可观察的回退；离线对照评测则拒绝回退，避免把BM25结果计作向量成功。

会话快照冻结检索模式、索引身份、RRF和候选参数；进行中切换配置或索引会返回`assets_changed`，应恢复原配置或新建面试。默认BM25的旧快照无需新建即可恢复。当前会话查询仍以主题/难度为主，没有加入简历全文语义召回。
