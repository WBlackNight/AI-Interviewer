# 后台差距评估与优先级执行

评估对象为本项目实际运行的 `/admin`，依据 `frontend/admin`、后台 API、数据库模型、配置及自动化测试核对。优先级表示实施顺序：P0 为权限与数据可信基础，P1 为日常运营闭环，P2 为需要独立设计的后续模块。复杂度按低（单模块）、中（前后端联动）、高（跨业务与运维）分类，不代表固定工期。

## 当前定位与可保留能力

已有工作台具备侧边导航、运营指标、趋势与分布图、练习/题库/账户摘要、组合搜索、分页和详情；筛选通过 URL 保存，支持前进后退。图表基于真实数据，有文字和表格替代；页面已覆盖加载、空、无权限及错误状态，使用现有绿色主题和响应式布局。接口默认拒绝未授权账户，列表排除回答、简历、邮箱正文和登录凭据。

改进前的主要限制是只读查询：不能在后台分配只读角色、导出筛选结果、记录审校流程或追踪操作。题库发布和数据库备份已有项目工具，但没有完整的网页运营流程。业务评分和会话时间存储也沿用既有约定，不因新增后台而自动变成可比较的运营质量指标。

## 对照依据

权限设计参考 [OWASP 授权指南](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)的最小权限、默认拒绝、逐请求校验原则。对本项目的直接含义是区分只读查看与导出、审校等操作，并在服务端执行权限限制。

操作追踪参考 [Google Cloud Audit Logs](https://docs.cloud.google.com/logging/docs/audit)记录操作者、操作对象和时间的思路；本项目采用应用级操作记录，没有宣称具备云审计产品的防篡改、独立存储及合规能力。

查询交互参考 [MOJ 搜索组件](https://design-patterns.service.justice.gov.uk/components/search/)及其列表、筛选和分页设计方向，结合本项目实际资源增加日期、排序和恢复入口。上述资料提供设计依据，以下差距判断来自项目代码，未将其他网站的所有功能照搬为必须项。

## 本轮实现边界与配置

新增 `ADMIN_VIEWER_ACCOUNT_IDS`，与 `ADMIN_ACCOUNT_IDS` 一样接收32位账户ID，多个用英文逗号分隔，均默认留空。管理员拥有当前后台全部能力；只读观察员可看概览、业务列表及审校结果，没有CSV导出、审校写入和操作记录读取权限。同时出现在两份名单时按管理员处理。配置变更需重启服务，本轮未改实际 `.env`。

新增迁移 `006_admin_operations`：`admin_question_review`保存题目审校版本；`admin_audit`保存操作摘要。账户删除不因审计外键阻塞；原操作者注销后展示“已注销账户”，审计中仍保留原内部ID供后续保留周期策略处理。无网页删除操作记录入口，但拥有数据库写权限的人员仍能修改记录，当前不提供防篡改保证。

审计范围是成功的审校保存、成功的CSV生成，以及观察员请求受限操作时的权限拒绝。普通账户被后台入口拒绝、查询行为、输入校验失败、409冲突及下载到本地是否完成不作为上述成功操作记录。CSV成功提示只表示文件已生成并交给浏览器，不代表用户已保存到磁盘。出现网络错误时，应重新读取确认审校状态，不自动重放写请求。

日期按北京时间自然日包含起止两天；练习按开始时间筛选，未启动场次不匹配日期范围。账户按注册时间，审计按操作时间。现有练习本地naive时间/账户UTC时间由接口适配，跨时区迁移前仍应安排统一UTC存储升级。

前端继续使用React、TypeScript、Vite与现有Hook和账户协议；后端继续使用FastAPI、SQLAlchemy与现有版本升级机制。本轮没有新增依赖。前端 `ReviewEditor.tsx` 独立维护审校表单；`services/admin_operations.py` 承接审校、导出和审计，通用统计保留在 `services/admin.py`。

## 验证与维护

自动化：60项前端测试，71项相关后端测试及37组页面检查通过，包含账户/会话/资料回归、角色限制、配置撤销、隐私排除、时间范围、CSV公式注入与导出上限、内容变化、版本冲突、原子审计、安全错误与迁移重复执行。账户旧断言已更新以包含当前接口新增的管理入口标志，继续严格核对所有其他资料字段。Vite严格类型检查、格式检查及四入口构建通过，后台压缩脚本约180KB，保持在原190KB预算内。

构建顺序：在 `frontend` 执行 `npm run build`，根目录执行 `python tools/project.py build`。新增表沿用应用启动升级流程。隔离预览仍使用3202端口及原有测试库，升级前已备份至本轮日志目录；未修改正式业务库，未调用外部模型、邮件或语音服务。

实屏验收完成测试账户登录回跳、审校保存后重新读取、需修改筛选、CSV实际下载（1条、7列且题目编号匹配）、审校与导出操作记录、记录类型筛选、详情与Escape关闭、同日日期范围与最早排序。390px筛选控件正常换行；320px页面与详情窗口均未横向溢出。切换分区时曾发现旧列表短暂套用新表头，已通过绘制前清理加载状态修复；操作详情独立使用操作时间名称。已恢复临时视口并保留预览。
