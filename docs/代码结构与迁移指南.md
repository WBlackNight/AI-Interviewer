# 代码结构与迁移指南

当前运行入口为 FastAPI 同源服务，提供原生页面、REST API 和 WebSocket。日常开发从项目根目录的 tools/project.py 进入。

| 助手服务与知识 | backend/app/services/assistant.py、data/assistant_guides.json | 受限只读工具、题库检索、流式生成及明确兜底 |
| 岗位规则 | data/roles.json、backend/app/practice_policy.py | 岗位名称、分组、时长题量与前后端共享目录 |
| HTTP 入口 | backend/app/api | 参数校验、认证、调用服务和返回响应 |

| 账户复习重点 | backend/app/services/practice_focus.py | 读取最近已完成练习的数值摘要，不读取原回答 |
| 评测诊断 | backend/app/services/assessment.py | 从已有回答证据生成表现与补强建议 |

| 数据存储 | backend/app/models、repositories.py | ORM 实体及持久化操作 |
| 数据升级 | backend/app/schema_versions.py | 按顺序登记和执行数据库升级 |
| 开发命令 | tools | 构建、检查、启动、备份与前端打包 |

根目录HTML和assets是构建产物。修改原生页面后运行build，再运行check。小青与文字练习室采用独立React入口；修改frontend/assistant、studio、shared或lib后，在frontend运行npm run build（包含严格类型检查），再构建ui。ui/compiled保存Vite产物及源码哈希，Python构建拒绝过期产物。frontend/app保留Next历史兼容页面，正式入口不加载它们。迁移范围见《技术栈迁移与优先级执行-2026-11-16》。

逐题复练集中在 services/question_retry.py，处理固定题目、题目版本和报告对照。个人复习导出集中在 services/revision_export.py，字段白名单和行数上限在此维护。公共响应头和校验消息集中在 api/http_policy.py。

## 跨目录启动

使用 Python 3.12 创建虚拟环境，安装 backend/requirements.txt。Windows 可使用 backend/.venv/Scripts/python.exe，Linux 可使用虚拟环境中的 Python。

```text
python tools/project.py build
python tools/project.py check
python tools/project.py serve --port 3000
```

serve 使用当前解释器启动 FastAPI，并固定子进程工作目录为 backend，因此 backend/.env 和既有相对 SQLite 配置含义一致。外部环境变量优先于 .env。使用绝对脚本路径，也可以从其他目录执行。

独立离线演示可指定数据库文件。

```text
python tools/project.py serve --offline --database backend/demo.sqlite3 --port 3000
```

--database 相对于调用者当前目录解析为绝对路径，父目录必须存在。省略此参数时沿用现有 DATABASE_URL。--offline 在子进程中关闭外部模型、语音、邮件和沙箱调用，采用 BM25 检索。开发时可加 --reload 自动加载源码变动。

默认监听 127.0.0.1，单进程运行。需要公网访问时，通过部署环境配置 HTTPS 代理和访问控制。服务长期托管交给部署环境的进程管理工具。

## 迁移到新机器

1. 复制或检出同一份已验收源码，记录发布版本，安装依赖。
2. 按 backend/.env.example 创建本机配置，分别设置密钥和数据库路径。
3. 构建 ui 并运行前端检查。
4. 备份原机器的实际数据库，将备份放在新机器的独立数据路径。
5. 在 backend 目录运行 python -m app.manage_database status 和 upgrade，核对已应用版本。
6. 使用 serve 启动，验证登录、练习恢复、报告和分享撤销。
7. 保存旧代码与升级前备份，准备回退点。

SQLite 备份工具使用在线备份并检查完整性，目标文件必须尚未存在。个人导出覆盖复习资料，完整迁移应使用数据库备份。PostgreSQL 配置和升级需在目标 PostgreSQL 环境单独验证。

数据库升级、备份与恢复细节见[数据库版本与运维](数据库版本与运维.md)。

## 模块与资源

首页入口保留在pages/home.js，六个功能片段在modules/home。工作区样式按12个业务域拆分到styles/workspace。两类片段均在构建时合并，每页仍是HTML、CSS、页面JS、公共账户菜单JS四个静态请求。

共享http.js负责新JSON请求的超时、取消、错误和账户复核。会话创建、简历上传、评分及音频不启用自动重试；WebSocket仍独立管理回合版本和重复消息。

完整变更与边界见[报告驱动重构与验收](报告驱动重构与验收-2026-11-15.md)。
