# 界面美化与动效优化

延续纸白与青绿主题，调整公共底色、导航选中态、主按钮和卡片阴影。首页首屏使用静态柔和渐变，收紧标题与产品演示之间的间距；保留内容居中和现有路由。工作区卡片统一为柔和边框与轻阴影，输入聚焦有明确轮廓，滚动条采用较细的绿色样式，高对比度模式恢复系统配色。

小青浮窗提高正文、说明、字数与底部提示的可读性，增强按钮悬停与输入聚焦反馈。较矮窗口隐藏重复装饰标识，登录入口并排展示，避免欢迎内容出现不必要滚动。头像弹窗优化顶部层次、说明文字、关闭按钮点击范围与拖放区域反馈，保持本地选图和手动保存流程。

动效以160ms控件反馈、240ms内容切换、360ms首屏入场为基础。首页演示回答与追问的延迟从650/1200ms缩短为160/300ms。岗位卡片悬停轻移2px，桌宠吸边平滑过渡240ms，聊天收起140ms；重新打开会取消未完成的收起，退出期间内容不可操作。减少动态效果时跳过这些移动与退出动画，后台标签页暂停桌宠循环动画。

设计参考[Microsoft Fluent 2动效指南](https://fluent2.microsoft.design/motion/)，采用短时长、统一缓动、围绕当前操作提供反馈的原则。未引入额外动效依赖，也没有为流式输出的每个字符添加动画。

## 提示与字体间距续调

公共样式增加控件间距8px、提示间距8px、表单项间距16px与正文行高1.8的变量。调整首页、账户、练习室、小青和弹窗的提示留白，清理空提示占位；弹窗标题取消通用20px上边距，头像说明距标题8px，裁剪区标签避免重复叠加外边距。移动端标题字号随可用宽度调整，320px导航与练习方式按钮保持完整显示。

实屏测量：首页提示到控件8px、相邻表单项16px；头像标题margin为0、说明间距8px。320px首页无横向溢出，390px及1280px头像弹窗在视口内。构建、格式与36组UI检查通过。证据保存在`docs/logs/2026-11-17/spacing/`，本次仅修改样式。
