## 成套准备与校验

```powershell
# 仅写入全新目录，不读取.env或请求供应商。
.\backend\.venv\Scripts\python.exe evals/prepare_question_release.py --skill-overrides data/skill_tree_candidates --output docs/releases/new-local-release
.\backend\.venv\Scripts\python.exe evals/prepare_question_release.py --verify docs/releases/2026-10-28-candidate-v1
.\backend\.venv\Scripts\python.exe evals/review_candidate_answers.py --release docs/releases/2026-10-28-candidate-v1 --json-out docs/logs/answer-review-local.json
```

包包含baseline18题/candidate24题两套question_bank、skill_tree、来源登记、独立hash-256索引及manifest.json。先完成复制、严格审校、合并、索引和自验，再同级重命名，失败不留下正式目标；已有目标只可verify，不覆盖。prepare/verify退出0表示结构、成员摘要与索引一致，不表示语义、人工质量或发布成功。review退出0仅表示作者样例对照执行完成；检查其中extra_hit_cases/missing_hit_cases，independent_quality_verified和activation_recommended始终为false。

文件清单最多64成员，清单最多256KiB；题库审校仍应用下文各项限制。成员禁止路径越界和链接，单成员最多32MiB；校验成员集合、SHA256、路由、题库域摘要与完整索引，摘要不是签名。--json-out应置于包和输入目录以外，避免报告破坏资产或样例。解压交付ZIP后可直接对解压根目录verify。

新增YAML可选question_routes：题号→完整节点路径，首次追问从主问题主题进入；后续沿已保存节点继续。技能树加载要求路径存在，审校要求题号/岗位/根主题一致；路由表进入会话资产版本保护，无路由旧资产摘要保持兼容。候选树单独在data/skill_tree_candidates，现行树未改。

用包启动隔离验收：

```powershell
.\backend\.venv\Scripts\python.exe evals/smoke_e2e.py --start-server --restart --pdf --asset-release docs/releases/2026-10-28-candidate-v1 --asset-variant candidate --retrieval hybrid --position python_backend
```

--asset-variant baseline可验收旧18题。此模式先校验包，再同时选择题库/树/索引，限包内hash索引，默认仍关闭LLM。hash为词法基线，不能沿用“语义模型已通过”的说法。恢复原生产智谱配置须使用与原题库匹配的原索引；候选智谱索引需在质量处理后另建，不能混配18题旧索引与24题候选。当前没有发布API或自动激活。

## 只读审校

在项目根目录执行：

```powershell
.\backend\.venv\Scripts\python.exe evals/audit_question_bank.py --candidates data/question_candidates --json-out docs/logs/question-audit-local.json
```

可选--bank-dir、--skill-tree-dir、--sources指定副本路径，--candidates省略时仅检查当前题库。脚本不读取.env、不启动服务、不联网、不执行编码用例、不修改输入文件或索引；只在显式--json-out位置写报告。退出0为结构与来源登记检查通过，退出1为失败。错误只输出相对分组/文件名、行号和固定代码，不回显输入、答案或解析异常正文。

检查字段及类型、ID格式、长度、难度白名单、非空锚点/关键词、锚点重复、编码题用例与UTF-8大小、全局ID唯一、同岗位题干去空白/忽略大小写后重复、岗位与技能根主题、来源登记。单文件上限10MiB，记录上限10,000；用例最多12个，每个输入/期望各64KiB UTF-8。不同岗位可以保留不同ID的同题定义，例如现有两数之和。空文件或仅注释/空白的分组不能作为题目集合通过，输出NO_QUESTION_RECORDS；目录没有JSONL时仍为NO_QUESTION_FILES。

公开覆盖统计不读取锚点或用例；离线审校会读取它们检查结构，报告不输出内容。运行时原QuestionBank加载行为保持，审校工具是独立维护入口，不会自动强制发布或把候选目录加入服务。

## 来源声明与证据

question_bank/source_registry.json格式版本1，来源ID唯一，包含label、origin、review_state和references。当前两个旧来源为self_authored/unreviewed，依据本地README的项目自编声明；新候选4组来源为reference_checked，附官方HTTPS链接及核对日期。许可来源类型预留为licensed，仅为来源声明，本轮没有实际许可来源，也没有验证第三方许可。

登记文件最多256KiB/1,000来源；拒绝带凭据、非HTTPS或含空白的参考URL，reference_checked必须有资料。服务不会自动请求参考链接。缺失或无效登记不阻断面试，只在覆盖页显示未登记；CLI则以失败提示修复。参考页面会更新，应保留当次记录与文件摘要，不能据此声称永久有效或已完成专家审题。

corpus_sha256沿用索引的题目域摘要，包含题目身份、内容及锚点等域字段，不包含登记JSON和技能树。离线报告保存题库/候选JSONL摘要；本轮日志另保存source_registry.json快照及摘要。正式切换须记录题库、技能树、登记文件、索引模型/版本/摘要的完整清单。

## 候选到运行题库

1. 在候选目录编写不同ID的自编题，登记来源；先跑只读审校。当前六题分别补Spring基础/挑战、Redis基础/挑战、Python基础挑战、异步基础，仍未激活。
2. 检查题意、版本前提、锚点与完整/部分/错误回答，关注仅命中一个关键词被误评分的问题。离线启发式通过不证明语义质量。候选Python拷贝题的对象共享/浅深拷贝、memo与资源技能路径及题号路由已补齐并隔离验证；继续审阅概念关系误判，现行技能树保持。
3. 在题库与技能树副本中合并候选，保留旧版本；用独立索引路径构建并确认摘要一致。按现有配置显式选择hash离线或真实Embedding，不能把hash结果称为语义效果。当前构建脚本会读取服务配置，真实Embedding需按其原有供应商与预算流程运行；本轮没有执行该脚本或读取密钥。
4. 用副本启动隔离服务，验证岗位、严格浏览/出题放宽区别、知识/编码范围、专项、追问、完整报告和重启；再选择一致的题库、技能树、索引配置切换服务。进行中旧场会按原资产版本保护拒绝继续，需保留原配置完成/取消，或新建练习，不能把新题静默套进旧场。
5. 同步首页本地题数/主题快照和相关smoke预期，再集中回归。保留回滚所需旧文件及清单，不直接覆盖唯一索引。

这些步骤是维护流程，不是新增发布API，也没有后台上传、自动激活或自动调用供应商。下一批工作按候选审阅和隔离验证推进，不以结构审校替代内容判断。
