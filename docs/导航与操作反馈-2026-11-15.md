# 顶部导航、首页演示与操作反馈

本轮统一首页和工作区的顶部导航，从ui/manifest.json生成“首页、练习概览、练习方向、题库探索、更多功能”。更多功能按我的准备、记录与复盘、账户与帮助分组，菜单名称不再随页面变化。练习室和报告页保留场景导航，目的地名称与主导航一致。

当前页面使用aria-current=page；题库覆盖、计划记录分别关联题库探索、准备计划，使用aria-current=location标记所属模块。原路径和兼容跳转继续有效，首页也提供直接返回首页的常用入口。

首页首屏预填问题、回答、追问和复盘内容，约4.8秒切换环节。回答与提示分步入场。滚出视口、隐藏标签页、悬停、键盘聚焦及减少动态效果设置会暂停自动播放；左侧01、02、03仍可点击或用方向键切换。示例内容已明确标注为演示。

轻提示通过shared/notice.js发送显式操作结果，shared/feedback.js在公共菜单脚本中统一渲染。成功与失败分别采用状态和警告语义，显示2000ms后关闭，可手动关闭；连续操作替换当前提示，避免堆叠。不将后台读取包装为成功通知，也不自动重试写操作。

目前覆盖复制配置、创建练习、登录注册、退出登录、资料、头像、邮箱绑定、密码、会话管理、收藏整理、准备计划、笔记保存、复习任务更新和导出等主要操作。表单旁的详细错误继续保留。发生导航时，仅通用成功文案通过标签页临时存储传递，十秒失效、读取即删除，不携带账户或简历内容。

维护入口：ui/shared/notice.js、feedback.js；ui/modules/home/demonstration.js；ui/styles/70-workspace-shell.css、85-practice-experience.css；tools/build_ui.py。首页和记录页的脚本预算分别为34KB和16KB，账户页维持42KB；未增加静态请求。

验收：33组前端检查通过；34项原生路由与网关检查通过；3项打包边界检查通过。新增时序检查覆盖2秒关闭、通知替换与清理、导航后恢复、过期提示，以及演示的视口、悬停、聚焦、减少动态效果和往返缓存恢复。

本机实屏看到首屏自动切换至追问，复制配置成功提示、错误密码失败提示均正常出现并关闭，表单错误保留。390px手机下内容宽359、视口文档宽375，无横向溢出，导航高亮及分组展开正常。截图和前端检查结果位于docs/logs/2026-11-15/navigation-feedback/。
