# 后台工作台：架构分析与接入

> 本文保留首次后台接入的架构说明和当时验收结果。后续已新增观察员角色、导出、版本化审校、操作记录及数据库迁移006；当前功能、配置与限制以[后台差距评估与优先级执行](后台差距评估与优先级执行-2026-11-17.md)为准，下文“只读”“不改变数据库结构”描述的是首次接入范围。

## 现有架构与本次选择

| 层级 | 现有组织 | 本次接入 |
| --- | --- | --- |
| 页面登记与路由 | `ui/manifest.json`统一登记；FastAPI的`api/frontend.py`同源提供页面、HTML别名与规范跳转；练习和报告使用带ID的路由 | 登记`/admin`；后台分区使用`view`查询参数，筛选、页码随地址保存，支持刷新及前进后退 |
| 页面与组件 | 原生页面由`ui/templates`、`pages`、`modules`、`shared`组成；小青、练习室和悬浮聊天使用React、TypeScript及Vite | 新增`frontend/admin`独立入口，按工作台、指标、筛选、表格、详情、图表、状态和传输拆分 |
| 状态与数据 | React Hook管理交互；账户会话保留在当前标签页，使用Bearer请求头；写入与读取均有身份复核 | 沿用会话契约与账户事件，URL管理可分享的非敏感筛选，Hook负责加载、取消、超时和失败恢复；异步返回时再次核对身份 |
| 样式 | 公共CSS变量、分层样式与按页独立样式；Python组装并附加内容摘要版本号 | `100-admin.css`仅加入后台CSS，复用现有色板、按钮、间距、焦点及减少动态效果设置 |
| 后端 | FastAPI路由、业务服务、SQLAlchemy实体分层，现有SQLite与版本升级机制 | 新增`api/admin.py`及`services/admin.py`；不改变数据库结构，不引入新的运行依赖 |

后台是独立的只读运营工作台，包含运营概览、练习记录、题库目录、用户概况四个分区。使用侧边导航和顶部信息区；业务页面仍使用原有导航。后台复用账户菜单，不叠加业务页的桌宠入口。

## 功能与交互

- 概览显示累计练习、已完成练习、注册账户、运行题库；提供7/14/30/90天趋势、练习状态分布、各方向题量和已评分回答均分。
- 练习记录支持场次编号或用户名搜索、方向与状态筛选，展示评分轮数和时间。
- 题库目录读取当前运行题库，支持关键词、方向、难度和题型筛选。来源与题干可在详情窗口完整阅读。
- 用户概况支持用户名/昵称搜索及邮箱绑定状态筛选，展示注册时间、练习数量、有效会话数量。
- 表格服务端分页，每页10/20/50条，条件改变回到第一页；查看详情使用原生模态窗口，支持Escape关闭及焦点恢复。
- 提供首次加载骨架、错误重试、未登录、无权限、空结果及清除筛选状态。移动端导航可折叠，表格在容器内横向滚动，页面本身不横向溢出。
- 图表使用SVG与原生meter，不引入图表库。趋势线共享同一纵轴；状态分布同时提供文字、数值与颜色图例。趋势另有可展开的数据表，便于辅助技术读取。

## 权限与数据范围

管理员由服务端配置`ADMIN_ACCOUNT_IDS`明确指定，值为账户表中的32位账户ID，多个以英文逗号分隔。留空时没有账户拥有后台权限。账户删除后再注册不会凭相同用户名自动获得权限。

在实际部署使用的`backend/.env`中填写所需ID后，重启后端使配置生效。`backend/.env.example`保留空值。不要填写用户名、密码或会话令牌。本次未修改本机`.env`，仅在3202隔离预览进程中，为测试账户`qing_review`设置了明确的访问权限。

登录后，`/api/auth/me`返回本账户是否具备管理权限，账户菜单按此显示“管理工作台”。菜单显示仅用于交互，所有`/api/admin/*`接口仍独立校验当前有效账户和管理员ID；未登录返回401，普通账户返回403。配置撤销后原会话也失去管理访问权限。

后台不返回简历、回答正文、邮箱地址、密码散列、验证码、头像二进制或登录凭据。用户列表仅返回邮箱是否绑定。接口禁用缓存，管理页面禁止搜索引擎索引；站内管理员身份不会绕过原练习/报告的所有者校验。

## 统计口径

累计指标来自当前数据库；题量来自当前生效的运行资产，不读取数据库里可能保留的旧题版本。完成率为已完成场次/全部场次。回答均分按所有已评分回答轮次计算，空样本显示“—”，不制造零分或趋势。

趋势按北京时间自然日分别统计启动与完成；未启动场次只计入累计练习。沿用项目既有时间存储约定：练习时间为宿主本地naive时间，账户创建时间为UTC；接口统一转换为带时区的时间字符串。趋势同一天的启动与完成不要求来自同一批场次。

## 维护与验收

主要源码位于`frontend/admin/`，接口位于`backend/app/api/admin.py`与`services/admin.py`；模板为`ui/templates/admin.html`，样式为`ui/styles/100-admin.css`。

修改后先在frontend执行`npm run build`，再回根目录执行`python tools/project.py build`。Vite开发服务支持`/admin`并复用现有API代理。构建器对四个React入口执行源码哈希核对；源码打包包含admin模块与开发HTML。

已通过59项前端测试、14项相关后端测试及37组UI检查。覆盖默认拒绝、普通账户拒绝、权限撤销、敏感字段排除、实际计数、时区日界、筛选与分页、输入边界、共享纵轴、异步身份变化及原有页面入口。

实屏验证：管理员登录回跳、四个分区切换、题库第二页、教育方向与“课堂”组合搜索、空结果恢复、详情和Escape关闭，以及390px折叠导航、320px页面无横向溢出。预览使用既有隔离库实际记录，未添加虚构增长指标或用户数据。截图与日志保存在`docs/logs/2026-11-17/admin/`。
