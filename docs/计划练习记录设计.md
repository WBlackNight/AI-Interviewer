# 计划练习记录

日期：2026-10-27（北京时间）。在准备计划已有关联上增加分页回看，不新增表、列或内容副本。

## 读取契约

GET `/api/account/preparation-plans/{plan_id}/practices`，账户Authorization、no-store。先核对计划归属，再按计划关联与面试ResourceOwner共同归属过滤，未知/他人/已移除计划统一404，无会话401。归档计划仍可读取；即便存在错误的跨账户关联，也不会返回另一账户面试。

可选status仅created/running/finished/cancelled，offset为0–1,000,000，limit为1–20、默认8。status_counts始终统计该计划全部仍存在且同属当前账户的关联场次，先于状态和分页；total为状态过滤后的总数。按preparation_practice递增ID倒序分页，同一时间创建也稳定，不按完成或活动时间重排。并发新增可能使offset分页移动，不承诺跨多次请求的固定快照。

响应包含plan当前id/name/position/themes/difficulty/status/target_date，items、total、offset、limit、has_more、status、status_counts以及timezone=Asia/Shanghai。items沿用history.summaries的岗位、难度、状态、主题数、已保存回答轮数、开始/结束/最近活动时间，另加saved_at。saved_at取本场ResourceOwner创建时间（UTC），计划新建练习时在同一事务写入；它不表示独立记录过的关联时间。排序使用关联ID。摘要只批量查询当前页的回答数量和最近活动，不返回回答、题干、简历、评分要点或分数，不加载题库、Embedding或调用供应商；现有岗位显示名仍通过技能树解析。

## 页面与恢复

新增`plan-history.html`及`assets/plan-history.js`，路由`/plan-history?plan_id=...`，与全工作区共用home.css。准备计划卡片新增入口，保留旧继续/最近报告入口。记录页显示当前计划范围/目标日/状态、四类计数，八项分页、状态筛选/清除、刷新，活动场次可进入或继续，任何状态可读当前报告，完成场次标明完整报告。打开练习室会沿原流程开始/继续，单纯读列表不创建或启动练习。

地址只保留合法计划ID、白名单status及正整数page；页码1–125001，与offset上限对应。刷新按地址恢复；筛选或清除回第一页，超出当前范围回到有效末页（无匹配回第一页），读取失败可重试。未指定计划显示选择引导，参数无效明确提示从准备计划重开；无会话或失效时隐藏旧内容。异步返回校验请求版本与同一会话令牌，pagehide中止读取，bfcache返回重读。名称、日期和凭据不进入地址或新持久存储。

所有日期按北京时间格式化，服务端时间戳保持原UTC接口契约。手机双列计数、单列记录、两列筛选控件，桌面双列记录；单条结果全宽，无滚动劫持。新脚本8,505原始UTF-8字节，页面仍3项静态请求，业务API另计。原计划页加强了会话令牌比较，防同账户重登后的旧请求回写；去掉主题包裹label内部冗余for/id，保留原生关联及可访问名称，原计划脚本14,994字节。

## 生命周期

归档或恢复不改练习与计数；读取当前计划名称和目标日，不生成历史版本。删除练习沿既有事务移除关联，列表与计数随之减少；移除已归档计划后本接口404，但原练习/报告仍可从全部练习访问。账户删除保留原进行中保护与清理顺序。数量只描述仍保留记录，不表示永久累计或能力变化。无自动提醒、写重试或新删除入口。

## 计划主题复盘与任务闭环（2026-10-27续）

在原记录页加入原生details，默认折叠，展开才GET `/api/account/preparation-plans/{plan_id}/review`。当前账户Authorization、no-store，先校验计划归属，未知/他人/已移除计划404；归档允许读取。theme可选1–64字，offset 0–1,000,000，limit 1–10默认4。只取共同归属、关联该计划且岗位相同的已完成有评分场次；进行中、取消及其他计划不进入结果或主题选项。

复用account_review内部算法，新增内部plan_id范围参数，不改变原账户复盘公开接口。默认主题取本计划已完成评分主题的首个排序项；明确指定的未知主题保留空结果，不扩大范围。每次只返回一个主题，按原完成时间/ID倒序，每页4场，返回原items/positions/theme/分页/来源版本等字段以及preparation_plan_id、weak_score。无新增内容副本、表或评分写入。

同一主问题各轮均值后，主题内主问题等权，结果与报告theme_avg一致。实际题目难度、评分来源及同ID同版本重复/未知版本计数保留；重复题仍按本账户全部先前已完成记录统计，包括计划外记录，不声称只在本计划内重复。界面显示设定强度、实际难度、主问题/轮数、来源计数，依据及详细版本通过原报告入口查看。不把不同场次再平均，也不把对照解释为能力提升。

模块主题与页码仅保留本页面内存，刷新回默认，不写个人URL字段；换主题回首四场，越界回最后有效页。模块读取失败单独报错/重试，不阻塞练习列表；账户失效仍隐藏整个个人区。主列表刷新/翻页会取消旧复盘读取，展开状态下再读，离页中断，异步版本与同一会话令牌保护。共用有界请求函数，保存中锁住两区控件并提供离页保护，旧写响应不得释放新操作或写回新会话。
