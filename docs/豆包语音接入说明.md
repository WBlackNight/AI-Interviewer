# 豆包语音接入与验收

更新：2026-10-29（北京时间）。已接入Seeduplex JSON适配与原生语音页面。确认凭据类型后，使用旧版APP ID与Access Token完成真实短音频转写、指定文本合成及网页保存/追问/朗读链路；747项回归通过。此前将两个值分别作为新版API Key时均返回401，该历史结果不代表旧版凭据无效。音质、识别质量、真机与计费尚未验收。

## 配置和入口

本地凭据只保存在backend/.env，不进入网页、日志、URL、交付包或示例文件。按控制台类型选择api_key或legacy，不能将Access Token和Secret Key分别当作新版API Key。当前本机已保存用户确认的APP ID及Access Token并选择legacy，不使用或保存用户Secret Key；开发配置仍默认关闭语音，既有LLM/Embedding配置不变。

```dotenv
VOICE_ENABLED=true
VOICE_ASR_PROVIDER=doubao
VOICE_TTS_PROVIDER=doubao
DOUBAO_VOICE_AUTH_MODE=legacy
DOUBAO_VOICE_APP_ID=在本机填写数字应用ID
DOUBAO_VOICE_ACCESS_TOKEN=在本机填写同一应用的AccessToken
DOUBAO_VOICE_MODEL=1.2.6.1
DOUBAO_VOICE_SPEAKER=zh_female_xiaohe_jupiter_bigtts
DOUBAO_VOICE_TIMEOUT_SECONDS=15
DOUBAO_VOICE_SESSION_SECONDS=120
DOUBAO_VOICE_MAX_CONNECTIONS=2
```

新版语音控制台则设置DOUBAO_VOICE_AUTH_MODE=api_key和DOUBAO_VOICE_API_KEY。两种模式互斥选择，资源须在对应项目开通。按[官方旧版鉴权说明](https://docs.volcengine.com/docs/DoubaoVoice/old-version-console-authentication-reference-example?lang=zh)，legacy发送X-Api-App-Id、X-Api-Access-Key及资源头；X-Api-App-Key为官方协议常量，不是用户Secret Key。

保留VOICE_ENABLED=false即可继续使用文字。修改环境后重启后端；不需要重新构建Next。本轮将本机已安装的websockets17.2显式锁定为直接后端依赖，不需要PyAudio，前端无新依赖。

当前文字练习室点击“语音作答”，同一场次地址增加?mode=voice，网关返回voice.html和assets/voice.js。返回文字时场次和访问归属不变。原生工作区现15个HTML、15个JS、共享CSS及接入README，共32文件；每页仍只有三个静态HTTP资源，业务API/WS另计。服务器部署时应为/interview/{32位id}按mode=voice选择voice.html，其他模式使用interview.html；两页的data-ws-base可留空使用正式同源WS，不能把本机预览的8000端口配置用于生产。

语音页支持朗读当前题、停止播报、主动录音及短WAV测试。音频开始前提示自动提交语义；ASR final会沿原面试轮次提交，answer_ack才表示已保存。代码题返回文字页填写代码。麦克风权限拒绝、设备断开、音频背压、连接关闭或识别失败均保留文字入口，断线不会自动重发录音。

```powershell

.\backend\.venv\Scripts\python.exe evals/native_home_preview.py --preview-minutes 240 --seed-notes --seed-history-states --seed-plan-history --voice-provider dummy

# 真实配置可用后才选择doubao，仍使用隔离演示库，点击音频操作会联系供应商。
.\backend\.venv\Scripts\python.exe evals/native_home_preview.py --preview-minutes 240 --voice-provider doubao
```

## 供应商适配边界

依据用户提供的python3.7_duplex_demo.zip及[官方全双工接口](https://docs.volcengine.com/docs/doubao-voice/end-to-end-real-time-voice-full-duplex-version?lang=zh)、[接入必读](https://docs.volcengine.com/docs/doubao-voice/access-must-read?lang=zh)核对协议：固定官方wss地址，服务端选择新版或旧版鉴权；session.create/close、音频append/commit与mute、transcription delta/completed。独立指定文本合成使用speech_text_buffer.commit（SayHello），先静音输入，再发送本项目确定的单句文本。replacement追加机制不用于这个独立播报场景。传输仍是Seeduplex JSON协议，旧版鉴权不代表切换数字事件二进制协议。

输入为16kHz单声道PCM16小端，网页以100ms网络帧上传，尾部不足一帧时补零送出；服务端保留前置缓冲。WAV按RIFF区块解析，校验格式、长度后按实际时长上传，不直接剥固定44字节头。浏览器通过恒定代码的Blob AudioWorklet采集，不下载脚本；严格CSP部署需允许该Blob模块加载，并在真实浏览器核验。麦克风采集需要安全上下文和用户授权。

输出显式申请24kHz单声道pcm_s16le，不把float32的pcm当作PCM16。服务端要求先收到chat_tts_text类型的audio.started；真实服务可省略音频分片的response_id，非空ID出现时必须一致，显式错配拒绝。该兼容限定在仅发送一次指定文本的独立会话中，音频先于start仍拒绝。另校验Base64、字节对齐、消息及总音频上限，再按原tts_chunk协议下发。网页按序播放，缓冲上限6秒；停止时先清理本地播放，再通知后端。适配器按段识别、按句合成，各自创建/关闭独立有界会话；正式评分模式仍按段识别/按句播报；另增实时陪练，使用持久连接接收自主S2S回复，见下节。

出题、追问、评分、回答保存均保持原项目流程。ASR阶段不转发供应商自由聊天结果，TTS使用本项目确定的题目文本；不启用示例的搜索工具、位置上报、函数执行或随机干预。没有供应商会话的自动重试、无限静音保活或原始PCM落库。

## 限制和观察

每进程默认最多两个供应商连接，超限直接拒绝，不排无限队列；创建/收发有超时，会话和音频总量有上限，关闭/取消释放连接。当前轮次、代码题、已结束状态在首次付费识别前校验；识别期间失败不提交截断转写，远端final与finish只提交一次。朗读只接收当前turn_id/version，不暴露任意文本合成接口，并有连接内冷却。

GET /api/voice/config只返回公开能力和格式；GET /api/diagnostics/voice提供连接/尝试计数，不返回凭据、转写或供应商错误正文。configured不代表已通过真实调用，质量/计费验证标记保持false。语音模型费用不计入现有文本LLM token预算；本轮没有配置价格、金额估算、跨进程全局配额或账户语音账本，生产上线前须补充预算与容量验收。

## 真实探针

```powershell
# 只检查凭据是否存在，不联网。
.\backend\.venv\Scripts\python.exe evals/doubao_voice_probe.py

# 显式联网：最多一段示例音频识别、一句固定文本合成；输出只写docs/logs。
.\backend\.venv\Scripts\python.exe evals/doubao_voice_probe.py --real --sample-zip "C:/Users/王小明/Downloads/python3.7_duplex_demo.zip" --json-out docs/logs/voice-probe.json --audio-out docs/logs/voice-probe.wav
```

探针只读取ZIP内指定WAV，不执行包内代码。报告默认只记录转写字数，不输出原文或凭据；生成音频可另存WAV。失败不切换替身、不自动重试；错误只保留固定类别、HTTP状态与经格式及凭据回显过滤的请求追踪号。

本次2.944秒示例完成真实转写；独立固定句合成得到113,988字节非静音PCM，24kHz单声道PCM16，时长2.37475秒。该单次探针首片2434ms、总耗时3094ms，不作为SLA。2026-10-29重新启动真实语音隔离预览后，浏览器WAV→转写→保存→追问→手动朗读通过，诊断记录ASR 1/1、TTS 2/2、活动连接0。短文件上传不会请求麦克风权限；语音体验续批已在文件上传时初始化音频上下文；朗读仍为显式入口。体验续批提供作答阶段、本段音频时长与播报状态，支持减少动态效果偏好，见[体验日志](开发日志-2026-10-29-语音体验优化.md)。没有做真人麦克风、跨浏览器、噪声或音质验收，未获取完整费用账本。最新证据见[联调日志](开发日志-2026-10-29-豆包旧版鉴权联调.md)和[证据目录](logs/2026-10-28/doubao-key-retry/)，原始失败批次保留在[历史日志](开发日志-2026-10-28-豆包语音接入.md)。

## 实时对话陪练

模型已通过同连接两轮自主回复、无强制commit的自然停顿及取消确认检测。新增?mode=realtime页面和/ws/realtime/{id}，共用已有鉴权；麦克风连续采集、服务端判停、双向字幕与语音回复，支持暂停和打断。该模式不自动保存正式回答或计入评分，页面字幕最多8条且不恢复。默认120秒有界会话，不自动重连。详见[实时语音日志](开发日志-2026-10-29-实时语音陪练.md)。
