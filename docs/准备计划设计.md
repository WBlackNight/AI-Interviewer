# 主动准备计划

日期：2026-10-27（北京时间）。用户主动安排下一段准备，与从已完成报告生成的复习任务分开，不以计划或练习数量推断能力。

## 数据与状态

preparation_plan保存账户ID、名称、岗位、themes、difficulty、可空target_date、active/archived状态、version及UTC创建/更新时间。名称去首尾空白，1–80个Unicode字符；每账户最多50份，含已归档计划，可移除已归档计划释放名额。允许同名计划，名称不是幂等键。目标日为2000–2100的YYYY-MM-DD日历值，按北京时间判断是否已过；没有提醒、自动完成或自动创建练习。

岗位、主题和强度在创建时通过当前practice_plan校验，范围保存后固定。PATCH仅允许名称、日期与状态，日期null可清空。真实变化才增加version，重复同值不改版本/时间；PATCH、开始和移除须带expected_version，旧版本409，他人/未知计划404。写操作先锁账户，与账户删除和同计划开始串行化。

preparation_practice以递增ID关联计划与唯一面试。保存计划不创建面试；开始在账户写锁内查找所属created/running场次，存在则返回同一场。完成或取消后才新建，原save_interview与关联在同事务写入，任一失败全部回滚。每主题最多两道知识主问题，保留原追问、采样和难度放宽规则，不复制简历、回答、评分、计划名称或目标日到新场。

## 列表口径

八份一页，按创建时间/id倒序，岗位元数据来自本账户全部计划。counts随岗位，不受状态及分页影响；past_target只计active且目标日早于今日，今日不计过期。列表带北京时间today，页面跨日需刷新。

每计划finished_count只统计仍存在、仍属本账户的关联面试中finished场次；取消不计，删除面试后会减少，不是永久累计。latest_practice为最新有效关联的id/status，聚合查询只返回当前页的有界摘要，不读取回答。available根据当前题库/主题上限计算；范围失效不可新建，已有场次仍可按原资产保护流程继续或取消，不能静默重建大纲。

## 接口

所有路径以/api/account/preparation-plans为前缀，当前账户Authorization，no-store。

| 方法 | 输入/结果 |
|---|---|
| GET | 可选position（1–64字符）、status=active/archived，offset 0–1,000,000、limit 1–20默认8；返回items、total、counts、positions、today/timezone和max_plans |
| POST | name、position、themes（至少1，服务端主题上限）、difficulty默认mid、target_date可空；返回id/version，不创建面试 |
| PATCH /{id} | expected_version、至少一项name/target_date/status；范围字段拒绝，返回id/version |
| POST /{id}/practice | 仅expected_version；返回interview_id、account_owned=true、access_token=null、preparation_plan_id、reused；新建还沿用原创建响应字段 |
| DELETE /{id}?expected_version=N | 只允许已归档计划，返回deleted=true；删除关联但保留面试 |

无自动写重试。创建计划只防本页重复点击，不声称跨请求幂等；超时先刷新核对。开始练习按现存活动关联复用，服务端并发验证四请求仅一场。

## 生命周期

归档可恢复，不取消任何练习，也不改变评分或其他任务。归档计划不能通过开始接口新建，但仍有已有场次链接和记录入口。移除已归档计划只清计划与关联，练习和报告独立保留。删除练习在原删除事务先清对应关联；删除账户先清所有关联/计划，保留原进行中面试阻止注销的规则。

没有新增身份、供应商请求或自动提醒。名称和日期仅当前账户可见，编辑/新建草稿只存页面内存，离页保护；版本冲突保留编辑输入。正式部署新增独立表由现有create_all补齐，无旧列修改；生产迁移、备份和多实例容量仍按原部署门槛验收。

## 来源回链与概览摘要（2026-10-27续）

新增GET `/api/account/preparation-plans/source/{interview_id}`，只接受账户Authorization。先确认该面试存在且归当前账户，再按同账户计划关联查找；未知/他人面试统一404，无会话401。返回`{source: null}`或`{source: {id, name, status, target_date}}`。无来源和已移除来源均返回null；归档计划保留来源。名称、状态与目标日读取当前值，不是练习开始时的历史快照。

报告页独立请求此接口，只显示当前名称、状态和来源入口，不修改原报告接口、报告导出、评分或运行快照。无来源隐藏来源区；读取失败保留报告，来源区提示刷新重试并提供计划入口；异步结果检查读取版本及当前会话，不把上一账户来源写入新页面。

列表GET新增可选`plan_id`（32位小写十六进制），与岗位/状态筛选取交集；counts与positions保持原口径，先于plan_id与状态/分页。无匹配仅返回空items，不泄漏存在性。前端`/plans?plan_id=...`默认全部状态，可直接定位归档计划或原列表第二页以后的计划，显示定位说明及返回全部入口。手动筛选或新建成功后清除定位和URL参数；名称、日期不写URL，原草稿保护保持。

账户概览GET `/api/account/dashboard`新增`preparation`：counts含active/archived/past_target，items最多3个活动计划，字段只有id/name/position/target_date，limit=3。目标日升序、无日期最后；同日期按创建时间/id倒序稳定排列。past_target只计活动且早于概览北京时间today的目标日，今日不计已过。聚合与三项限量查询不加载题库、不读取回答或额外创建练习，计划数量和日期不表示能力。无需新表、列或数据迁移。

## 计划内记录（2026-10-27续）

新增账户GET /{plan_id}/practices及独立计划练习记录页，四状态筛选、八项分页、刷新恢复、UTC时间的北京时间展示和原练习/报告入口。共同归属先于计数与分页，归档可读，删除练习重算，移除计划后404而练习保留。不新建表或改变评分，详见[记录设计](计划练习记录设计.md)。

计划主题复盘续批：记录页内接入同账户/同计划/同岗位的已完成主题对照，默认每页4场，按需读取并显式加入原报告复习任务，无新页面或评分更改。重复题口径仍为本账户先前同ID同版本，任务状态与复练独立。见[记录设计](计划练习记录设计.md)和[主流程交付](主流程交付清单.md)。
