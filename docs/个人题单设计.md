# 个人题单与学习标记

日期：2026-10-26（北京时间）。用于个人整理当前题库中的题目，与报告薄弱项生成的复习任务独立。

## 归属与保存

question_mark由账户独占，唯一键为account_id+position+question_id。每账户最多500条，收藏只接收岗位与题号并核对当前运行资产；不能注入题干或答案。题单允许知识题与编程题，不允许创建任意题库之外的新题。重复添加返回原id及reused=true，保持原状态、版本和时间，包括题目已下架的已有收藏。

独立表只包含id、account_id、position、question_id、status、version、created_at、reviewed_at。时间为UTC、响应带Z。内容按当前题库解析；不保存题干历史、评分锚点、用例、回答、笔记或简历。新表由已有启动create_all补齐，无既有列修改；生产迁移与备份仍按部署要求验收。

## 状态与并发

状态todo为待回看，done为已看过，均由用户手动修改。真正状态变化才增加version；done写入reviewed_at，恢复todo清空该时间。同状态重复提交不更改版本或时间。PATCH与DELETE必须带expected_version；不同账户访问不存在的题单id统一404，旧版本409。所有写操作先锁账户，新增还受唯一约束保护，避免重复收藏与账户删除交错。

收藏、手动标记和移除均不修改面试、评分、报告、复习任务和笔记；完成主题练习不自动改变标记。题目下架后仍可整理或移除，但不能练习；同一岗位与题号恢复后显示当前内容。同题号重用会被视为同一身份，因此内容管理应为不同题目分配新ID，而不是复用旧题号。

## 接口

所有接口使用当前账户Authorization、no-store，不接受URL令牌，不调用模型或召回。

| 方法与路径 | 输入与结果 |
|---|---|
| GET /api/account/question-marks | position可选1–64字符，status=todo/done可选，q可选最多100字符，offset 0–1,000,000、limit 1–24默认8；返回items、total、counts、positions、query及分页字段 |
| POST 同上 | 严格接收position/question_id各1–64字符；校验存在、账户范围去重及500上限，返回id/reused |
| PATCH /{id} | status=todo/done，expected_version为非负整数；旧版本409，返回id/status/version |
| DELETE /{id}?expected_version=N | 只移除本账户该收藏，旧版本409，返回deleted=true；再次移除404 |

列表稳定按收藏时间倒序、id倒序排列。岗位元数据来自账户全部收藏，包含已下架岗位；q去首尾空白并忽略大小写，字面匹配当前题干、主题、题号和来源，不匹配岗位内部编号。下架题只能按仍保存的题号匹配，不恢复旧内容。counts跟随岗位及关键词，先于状态过滤和分页。unavailable表示当前运行题库中无法找到，不推测历史题目内容。公开题库挑选继续使用/api/catalog，个人题单不向公开接口添加账户内容。

2026-10-26衔接补充：题库卡片可携带公开岗位/题号进入题单挑选框，登录前后通过白名单字段保留返回路径，不接受任意外部跳转；浏览/登录/返回均不自动收藏，仍需显式点击。个人关键词筛选只保留内存，刷新回默认；题库回链URL只含公开题目身份。两读取区失败分别展示，授权失效仍整体隐藏个人内容。

## 删除与练习

移除收藏使用独立确认框，明确原时间不可恢复；重新收藏会创建新的收藏记录。删除账户在同事务中删除全部question_mark，保留原进行中面试保护。删除面试、报告或复习任务不清题单；题单没有对这些资源的外键。

只有当前可练的知识根主题提供“练习本主题”。原POST /api/interview按当前岗位、该主题和独立强度创建账户专项，每主题最多两道主问题、保留追问、允许原难度放宽，不锁定收藏题。编程题只收藏回看；实际代码执行仍取决于原沙箱配置与验收。客户端写入无自动重试，超时提示先核对，创建结果已收到而导航失败时可进入同一结果。
