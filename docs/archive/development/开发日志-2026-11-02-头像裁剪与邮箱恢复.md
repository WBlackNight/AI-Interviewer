# 头像裁剪与邮箱恢复

本批以功能开发为主，未重复全量后端回归。

## 新功能

- 上传头像后在本地打开裁剪区域，拖动或使用水平/垂直滑块选取内容，缩放1–4倍，提供网格与圆形预览、重置和取消。保存尺寸可选128/256/512像素；客户端只上传裁剪后PNG，服务端再次校验并按选择尺寸重编码。原格式/2MiB/32–4096像素限制保留。图片解码迟到、账号变化及离页时清理资源，防止旧图上传至新会话。
- 登录页增加已绑定邮箱找回密码：图形验证码、邮箱6位验证码、两次新密码。验证码10分钟有效、单次使用，继承5次尝试限制。成功后撤销该账户全部会话与待处理验证码，用户重新登录。未知用户名或不匹配邮箱使用相同响应结构，邮件未配置时明确提示；发信仍使用既有SMTP/本机测试模式。
- 已登录账户可更换绑定邮箱，需要当前密码、新邮箱验证码。更换后清理旧邮箱对应的密码恢复和改密挑战。保留邮箱唯一约束。
- 裁剪器、恢复步骤和账户设置增加有限入场过渡；尊重减少动态效果设置。裁剪编辑打开时扩大编辑区域，窄屏单列，保留键盘滑块操作。

## 维护方式

avatarcrop.js与recovery.js以源模块注入账户页面，不增加运行时框架或全站脚本。账户页JS预算显式38KB。图片分割指选取并裁剪头像区域，不包含AI背景分割或多块图像导出。

## 验证与边界

本批头像尺寸、邮箱找回/更换和既有账户安全专项20项通过；最后邮件未配置提示由5项新功能专项再次通过，与20项有重叠。裁剪坐标、缩放/位置边界、输出尺寸、重置和资源释放离线验证通过；前端27个检查命令通过。证据在docs/logs/2026-11-02/avatar-recovery/。

没有新增真实邮件投递或真人麦克风调用，也未进行浏览器视觉验收。找回需事先绑定邮箱；未绑定不能通过用户名绕过验证。多进程需配置相同AUTH_CHALLENGE_SECRET。现有进程内登录限流没有在本批改为分布式实现，生产多实例仍需补齐共享限流并验证。当前恢复JSON不是数据恢复格式，不改变已有复习数据导出和数据库备份方式。
