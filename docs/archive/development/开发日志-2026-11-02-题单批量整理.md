# 题单批量整理与选择交互

日期：2026-11-02，北京时间。

我的题单增加当前页多选和全选，支持批量标记已看过、恢复待回看、确认后移除。题库挑选区可以一次收藏本组多道题，已有收藏保留原状态、版本与时间；反馈区区分新增数和已收藏数。选择仅在当前页面分组内有效，切页、筛选、刷新和账户失效会清空。

复选框沿用绿色主题，补充半选横线，卡片提供选中边框与浅绿表面。工具栏在小屏自动换行，交互目标至少44像素；保留原生复选框与键盘操作，状态计数由辅助技术播报。卡片有轻量出现和选中过渡，尊重prefers-reduced-motion。删除对话框展示数量与题号，取消保留选择。

新增POST和PATCH /api/account/question-marks/batch，每批1–24项，禁止重复身份、额外字段与布尔版本号。账户锁下先校验整个批次，再写入并统一提交：跨账户或已删除返回404，版本冲突返回409，新增越过500上限返回409。所有失败不产生部分写入。同状态标记不增长版本或覆盖时间。没有数据库列或运行题库变更，不调用模型、召回或语音服务。

维护源码仍在ui/，batchselect.js通过构建注入题单，不增加脚本请求；题单预算显式22,000字节，构建约19KB。生成library.html、assets/library.js与assets/home.css，并更新设计文档和文档索引。
